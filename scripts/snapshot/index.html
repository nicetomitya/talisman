Демонстрационный прототип. Все люди, компании, расчёты и документы вымышлены. Ни один документ не является действующим страховым полисом.

Талисман: прототип P0

Снимок настоящих экранов прототипа с демо-данными. Переходы между экранами работают, а кнопки действий в снимке ничего не выполняют, потому что за ним нет сервера.

С чего начать

  1. Заявки клиента: откройте заявку на КАСКО, затем сравнение предложений, сгруппированных по сопоставимым условиям.
  2. Полисы клиента: классические полисы и событийные RAIN01 (дождь на мероприятии) и WIND01 (недостаток ветра), с результатом проверки события.
  3. Лента агентства: заявки, на которые можно ответить, и окно приёма предложений по серверному времени.
  4. Автоответ агентства: правила, режимы «с подтверждением» и «автоматически».
  5. Обзор платформы: выручка платформы отдельно от объёма премий страховщикам.
  6. Очередь исключений: всё, что система передала людям.

Полная версия с работающими действиями (оформление, подпись кодом, оплата в эмуляторе, расчёт события) запускается локально по README из архива проекта.

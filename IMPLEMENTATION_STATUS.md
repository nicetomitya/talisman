## Изменения после P0

* 02.11.2026 — модель «матча» (D10 в `docs/DECISIONS.md`): подтверждение матча, закрытие торгов и уведомление остальных агентств, отмена матча только до оплаты, новая заявка тому же агентству. Тест: acceptance «Модель матча».
* 03.11.2026 — сроки и фиксированные условия (D11): подбор 24 ч, продление 15 мин (≤ 1 ч), 2 ч на оформление после матча с напоминаниями; цена только вниз, без повторной подачи после отзыва; маскировка контактов в чате; помощник для клиента («Проверить заявку», `GET /api/requests/{id}/review`) и разбор заявки для агентства. Тесты: scenarios «Фиксированные условия после подачи», «после матча 2 часа…», unit `assistant.test.ts`.

## Проверки

* `npm test` — 91 тест проходит (37 модульных, 54 интеграционных против реальной БД): `tests/unit/*`, `tests/integration/{security,money,scenarios,acceptance}.test.ts`.
* `npm run test:e2e` — 3 браузерных теста проходят: сценарий А целиком на 360 px и на десктопе; все публичные страницы и страницы кабинетов на 360 px (код 200, нет горизонтальной прокрутки, у каждого поля есть подпись, нет ошибок на странице).
* `npm run typecheck` — без ошибок.
* `npm run reset-demo` на пустой БД — миграции и сид за ~13 с, без ключей.
